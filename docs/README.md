# Docs

Everything we learn about the Skylight API and this agent’s scope lives under `docs/`.

- `docs/openapi/` — upstream + merged OpenAPI specs.
- `docs/findings.md` — notes and unknowns (IDs, auth, scoping).
- `docs/config.md` — env vars and scope configuration.
- `docs/commands.md` — CLI/MCP groups and entry points.
- `docs/har.md` — HAR capture notes.
- `docs/actions.md` — implemented CLI/MCP actions by section.
- `docs/cross-check.md` — cross-check summary (OpenAPI + bundle + HAR).
- `docs/capturing-api-traffic.md` — how to capture a HAR that includes API calls.
- `docs/har-endpoints.md` — endpoints observed in the latest HAR.
